开发可双击运行的桌面 EXE，实现：录音/导入 → 语音转写（含说话人分离）→ AI 总结 → 导出，可复制分发给他人零依赖使用。

## 核心成果
1. **端到端真机验证通过**：转写 example/zh.mp3 输出 `[00:00:00-00:00:05] 【说话人1】开饭时间：早上九点至下午五点。`，说话人分离 + 时间戳 + 中文转写全部正确。

## 关键技术决策
- 架构：进程内 AutoModel（非 server 子进程）
- 模型：Fun-ASR-Nano-2512 + cam++ + fsmn-vad + ct-punc（说话人分离）
- torch：2.5.1+cu121（CUDA 12.1，目标机 RTX 3060 走 GPU）
- 打包：PyInstaller onedir

## 关键踩坑（已解决）
1. remote_code 传绝对路径 → 模块名解析失败 → 改为省略参数，funasr 自动加载模型目录 model.py
2. 返回字段名 sentence（非 text）
3. torch CPU 版陷阱（阿里云 cu121 镜像实际装 CPU 版）

## 遗留问题（不影响使用）
