**最终产物文件夹：`C:\Users\<用户名>\Desktop\XPI\Meeting\dist\MeetingAssistant\`**

## 三、分发给别人用（5 个前提）

把整个 `MeetingAssistant` 文件夹拷贝给对方即可，对方**零依赖、双击 EXE 即用**。

| # | 前提 | 说明 |
|---|------|------|
| 1 | 整个文件夹一起拷 | 特别是 `mod/`（3.2GB）和 `_internal/`（4.1GB），缺一不可 |
| 2 | 对方 64 位 Windows 10/11 | 有 NVIDIA 显卡自动走 GPU（快）；无显卡自动降级 CPU |
| 3 | 首次运行填自己的 DeepSeek Key | 存各自本地 config.json，互不影响 |
| 4 | 需要麦克风 | 用于录音功能（导入音频文件则不需要） |
| 5 | 无需装 Python/任何环境 | 已全部打包 |

> ⚠️ 注意：整个文件夹约 7.4GB（模型 3.2GB + 依赖 4.1GB + 其他）。用 U 盘/网盘拷贝时请保留完整目录结构。

## 四、技术方案要点

1. **架构**：进程内调用 FunASR AutoModel（非 server 子进程），打包干净、分发无外部依赖
2. **模型**：Fun-ASR-Nano-2512（800M 参数，Audio Encoder + Qwen3-0.6B LLM），中文 CER 8.06%，优于 Whisper
3. **说话人分离**：官方标准组合 cam++ + fsmn-vad + ct-punc
4. **GPU 加速**：torch 2.5.1+cu121（CUDA 12.1），RTX 3060 走 GPU；无 GPU 自动 CPU 降级
5. **打包**：PyInstaller onedir（文件夹），避免 torch 单文件过大启动慢

## 五、关键踩坑记录（供后续维护参考）

1. **remote_code 不能传绝对路径**：funasr 会把路径当模块名解析失败。正确做法是省略 remote_code 参数，funasr 1.4.5 会自动加载模型目录内的 model.py（需 `trust_remote_code=True` + model.py 及依赖 ctc.py/tools 在模型目录内 + sys.path 含模型目录 + cwd 切到模型目录）
2. **返回字段名是 `sentence` 不是 `text`**：`res[0]["sentence_info"]` 每条含 start/end(ms)/sentence/spk
3. **torch wheel 来源**：官方 pytorch cu121 索引（阿里云镜像最高只有 2.5.1 且是 CPU 版陷阱）
4. **说话人分离 spk_model="cam++" 对 Nano 有效**（官方 2026/05/19 起支持）

## 六、已知遗留（不影响使用）

- `dist\MeetingAssistant\mod\mod\` 存在一个约 3.2GB 的冗余嵌套目录（复制操作产生的重复数据，删除需用户在系统里手动确认，不影响程序运行）。用户可在资源管理器中手动删除该目录释放空间。
