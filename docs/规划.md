# 智能会议纪要工具 — 工程规划与验证记录

## 目标
Windows 桌面会议纪要工具：录音/导入 → 语音转写（含说话人分离）→ AI 总结 → 导出 txt，双击即用，可复制分发。

## 目标运行环境
- CPU: AMD Ryzen 7 5800H
- 内存: 32GB
- GPU: NVIDIA RTX 3060 6GB
- 系统: Windows 11（兼容 Windows 10 x64）

## 构建环境（当前开发机）
- Windows 10 x64，Python 3.11.10（无 GPU —— 但 torch CUDA 版可在无 GPU 机器上安装与打包，仅无法本地测 GPU 推理）

## 技术选型（最终确定，已端到端验证）
| 模块 | 选型 | 状态 |
|------|------|------|
| 语音识别 | Fun-ASR-Nano-2512（800M，GPU 加速） | ✅ 已下载+验证 |

## 关键验证结论（2026-08-28，CPU 实测）
1. **FunASR 1.4.5（源码安装）+ AutoModel 成功加载 Fun-ASR-Nano-2512 本地模型**
2. **说话人分离 spk_model="cam++" 生效**（官方 demo_spk.py 确认支持）
3. **remote_code 必须指向模型目录内的 model.py**，且 model.py 依赖同目录 ctc.py + tools/（已复制到模型目录，目录自成一体）
4. **返回结构**：`res[0]["sentence_info"]` 每条含 `start/end(ms)/sentence(文本)/timestamp/spk(0起始)`
   - 注意：字段名是 `sentence` 不是 `text`
5. **实测转写**（example/zh.mp3）：`[00:00:00-00:00:05] 【说话人1】开饭时间：早上九点至下午五点。`
6. CPU 加载耗时约 60~90s（GPU 会更快），转写 RTF 0.04~0.5
7. Nano 自带标点，`punc_model` 参数对 Nano 不必要（返回 warning 但功能正常）

## 目录结构
```
Meeting/
├── src/                 # 源码（main.py, asr_engine.py）
├── venv/                # Python 虚拟环境
├── runtime/
│   ├── bin/ffmpeg.exe   # ffmpeg（98MB）
│   ├── mod/             # 模型文件（不打包）
│   └── wheels/          # torch wheel 备份

├── docs/                # 文档

```

## 分发方式（打包产物 = dist/MeetingAssistant/ 文件夹）
分发时需一起复制：
1. EXE 文件夹（dist/MeetingAssistant/）
2. `mod/` 模型文件夹（放 EXE 同级，约 3.3GB）
3. `bin/ffmpeg.exe`（放 EXE 同级）
4. `config.json`（首次运行自动生成，含各自 API Key）

对方零依赖，双击 EXE 即用；有 NVIDIA 显卡走 GPU，无显卡自动降级 CPU。
